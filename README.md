极简智能账务收支引擎 (AI语音驱动)
这是一个基于 Python + Tkinter 开发的完全由配置驱动的泛用型记账系统。内置本地 TTS 与 Whisper+DeepSeek 语音大脑，支持长按热键进行自然语言“对讲机式”记账。

✨ 核心特性
配置即软件：业务逻辑 100% 剥离，通过修改预设 JSON，可一秒将软件从“商业专业记账“切换为“剧本杀店算账”等任何场景。

AI 智能副官：接入 Whisper 本地粗听 + 大模型云端精准清洗，告别手动打字。

单机极速安全：SQLite 本地落盘，支持配置轻量级混淆加密，保护核心底线数据。

🚀 如何运行
安装 Python 3.x

pip install -r requirements.txt

运行 python hl.py
(普通玩家请直接在右侧 Releases 下载打包好的 exe 版本)
